How to flash

Follow these steps before pressing Flash Firmware.

1

Use a supported browser

Open this page in desktop Google Chrome or Microsoft Edge with Web Serial support.

2

Connect the ESP8266

Connect your NodeMCU ESP-12E to the computer using a USB data cable.

3

Close serial applications

Close Arduino Serial Monitor, PlatformIO, terminal programs and other applications that may already have the COM port open.

4

Press Flash Firmware

ESP Web Tools will open the browser's serial port selection dialog.

5

Select your ESP8266 serial port

Select the USB serial device belonging to your NodeMCU board and allow the browser to connect.

6

Start installation

ESP Web Tools will download the firmware from this website and write it to the ESP8266.

Important before flashing

Flashing replaces the firmware currently installed on the ESP8266. Make sure you have a backup of any important firmware or configuration before installing new firmware.

If the ESP8266 will not connect

Try manual bootloader mode.

A

Disconnect USB

Remove the USB cable from the NodeMCU.

B

Hold FLASH

Press and hold the FLASH button on the NodeMCU. On many ESP-12E boards this button is connected to GPIO0.

C

Connect USB

While holding FLASH, reconnect USB.

D

Release FLASH

Release the button after the USB connection has initialized.

E

Try Flash Firmware again

Select the newly detected serial port.

Troubleshooting

Common problems and solutions.

Failed to download manifest

Open the manifest URL directly in your browser. Confirm that it displays valid JSON. Check that manifest.json exists in the repository root and that the GitHub Pages URL is correct.

404 Page Not Found

Check GitHub Pages settings, branch selection, folder selection and the exact filename index.html. Wait a few minutes after publishing.

Firmware BIN not found

Confirm that the firmware directory contains exactly ESPRELAY.ino.bin and that manifest.json contains firmware/ESPRELAY.ino.bin.

No serial port appears

Try another USB cable. Some cables provide power only and do not carry data. Also install the USB serial driver required by your NodeMCU USB chip.

Port is busy

Close Arduino IDE Serial Monitor, PlatformIO, PuTTY, terminal applications and other programs that may be using the COM port.

Flashing connection fails

Disconnect/reconnect USB and try manual GPIO0 bootloader mode. Use a short, reliable USB data cable and avoid USB hubs during troubleshooting.

GitHub Pages cache problem

Hard-refresh the page with Ctrl+F5. Test the site in an Incognito/Private window and verify the raw manifest and BIN URLs separately.

ESP32-S3 connection problem

ESP32-S3 boards can expose native USB CDC and/or USB-JTAG depending on the board and firmware. Use a browser/device combination that supports Web Serial and select the correct USB serial interface. This particular manifest is for ESP8266 only.
